# HTML 实训：超链接和浮动框架（完成版）

本项目根据随附的《实训-超链接&浮动框架.docx》和 `t1.jpg`～`t7.jpg` 完成，共两个项目。

## 一、如何运行

1. 解压整个 ZIP 压缩包，**不要只解压单个 HTML 文件**。
2. 双击 `index.html`，建议使用 Chrome 或 Edge 打开。
3. 点击首页的两个项目卡片即可体验。**无需安装软件或启动服务器，可以离线使用**。

也可以分别打开 `course.html`（项目一）与 `gallery.html`（项目二）。

## 二、项目一：设计新生课程简介

- 在 `course.html` 使用 `<a href="#english">` 等超链接跳转到指定书签。
- 使用 `id="english"`、`id="math"`、`id="physics"` 定义定位点。
- 每门课程末尾的 `<a href="#top">` 链接返回页面顶部。
- 课程内容来自原实训文档，修正了文档中少量乱码标点。

## 三、项目二：设计简易灯箱画廊

- 展示配套 `assets/pic/t1.jpg` 至 `t7.jpg` 七张风景图片。
- 使用 CSS `@keyframes` 实现连续、无缝的横向循环滚动。
- 使用 `:hover` 与 `animation-play-state: paused` 实现鼠标移入暂停、移开恢复。
- 缩略图通过 `<a href="viewer.html?img=t1" target="photoFrame">` 等超链接，将图片预览页显示到 `<iframe name="photoFrame">` 浮动框架内。
- `viewer.html` 通过 URL 参数选择对应的图片；主页面的少量 JavaScript 负责同步图片标题与选中边框。
- 支持手机屏幕。系统启用“减少动态效果”时，出于无障碍考虑会停止连续滚动，但全部缩略图仍可单击。
